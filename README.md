# the-packstabbers-blues
Plugin for Blender that collects all PNG files from your project into one folder. Very easy to build TXD-dictionaries with it. Done with AI (Claude).

HOW TO INSTALL
1. Open "Edit" in your top bar menu in Blender
2. Go to "Preferences"
3. Go to "Add-ons"
4. Select "Install from disc"
5. Select the file packstabbers.py
6. Done! Anytime you want to pack your files, just press "File" in top bar menu and select "The Packstabber's Blues"

Enjoy!
